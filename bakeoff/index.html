Kateri glas zdrži deset ur?

Trije odlomki, isti za vsak glas. Imena so skrita, dokler jih ne razkriješ — da ne izbiraš po znanem imenu. B je neobdelan. C = B + popravljeno besedilo + tempo in soba. D = B + popravljeno besedilo, brez obdelave — primerjaj B, D in C zaporedoma. Ocene se shranijo v brskalniku.

Zveni robotsko? Tri različice istega glasu (p1)

Isti model, ista poved, ista glasnost. V1 = osnovno. V3 = toplejši EQ, blaga kompresija, mala soba. V4 = V3 + spremenljiv tempo in pavze po tipu povedi. V5 = V4 + dihanje na pavzah, počasen nagib tona in neprekinjen prostorski šum. Gibanje višine je pri vseh treh enako (5,2–5,7 poltona) — razlika je v barvi in ritmu.
